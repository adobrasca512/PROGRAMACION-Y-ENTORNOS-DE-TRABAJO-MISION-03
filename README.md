# Misión 3 · SQL — AI Customer Intelligence
**Autor/a:** Adilem Dobras Castillo
**Asignatura:** Programación y Entornos en IA · Máster en IA

## Archivos
- `01_creacion.sql`: crea la base de datos `ai_customer` y las tablas `clientes` y `operaciones` (con clave foránea).
- `02_datos.sql`: carga los datos de ejemplo (30 clientes y sus operaciones).
- `03_retos.sql`: consultas resueltas de los retos 1 a 4 y del reto final.
- `04_dataset_ia.sql`: consulta final del dataset para el modelo de abandono (una fila por cliente).
- `Informe_Mision3.docx`: informe de resultados.
- `clientes.csv`, `operaciones.csv`: fuentes originales de los datos.
- `Guia_alumnado.md`, `Rubrica.csv`, `Mision_3_SQL_presentacion.pptx`: material de la misión.

## Ejecución
Requisitos: MySQL 8 y MySQL Workbench (o DBeaver).

1. Ejecutar `01_creacion.sql`.
2. Ejecutar `02_datos.sql`.
3. Ejecutar `03_retos.sql` para ver los resultados de cada reto.
4. Ejecutar `04_dataset_ia.sql` para obtener el dataset final (30 filas, sin duplicados y sin nulos).

Los datos son sintéticos y exclusivamente didácticos.
